# 限定解除の所持免許判定

2026-09-11、学校回答「希望が四輪限定解除なら四輪免許、二輪限定解除なら二輪免許を対象。両方所持でも同じ」をユーザーが転送し、「これで一回直して」と修正を依頼。

## 今回の変更

- フォームの希望免許に四輪2種類（普通車AT解除、準中型5t解除）・二輪3種類（普通二輪MT、普通二輪AT、小型二輪AT解除）を追加。所持免許はすべて選択して保存する。
- GASでは限定解除を通常取得から分離し、希望と同じ系統の所持免許を参照。反対系統の免許・原付を審査区分の選択から除く。
- 正式2026-08-01 PDFの審査料金9行、学生/一般×デイ/フリーの36料金を使用。既存の通常PRICE_MASTERとMT卒業証明書移行36,300円は不変。
- 普通AT解除の4料金は62,150 / 67,150 / 67,650 / 72,650円。例えば普通AT＋普通二輪所持の一般フリーは72,650円。
- 二輪AT小型から普通MT二輪への審査は74,030 / 79,030 / 79,530 / 84,530円。四輪併有でも二輪のこの区分を使用。

## 確認待ちを維持する条件

旧フォームの「限定解除」だけの入力、四輪/二輪だけで解除先が不明、通常取得との複数希望、同じ系統に複数の審査区分、未対応免許・希望範囲取得済み、区分/プラン未選択は金額を推測しない。異なる料金だけでなく同額の別審査区分でも確認待ち。希望が通常取得の場合には、今回の限定解除規則を適用しない。

審査のオプション適用・追加割引は今回の学校回答では未確定。オプション付き審査を0円追加で確定させず確認待ちにする。既存の5件は解除種類等が未確定のため一括修復しない。顧客記録・メール・PDFの変更なし。
